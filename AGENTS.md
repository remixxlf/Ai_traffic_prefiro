## Core Rules
1. **Always invoke relevant skills** before taking action or writing code.
2. **Brainstorming first**: For any feature or task, understand constraints, present design, and get explicit approval before code.
3. **Test-Driven Development (TDD)**: Write failing tests before implementation code. Red -> Green -> Refactor.
4. **Verification Before Completion**: Run real verifications and tests before claiming a task is done.
